# Nexiam Landing Frontend - Coding Standards

## Development Guidelines
- Use Biome for linting and formatting (not ESLint)
- Follow Next.js 16 App Router conventions
- Use TypeScript for type safety
- Implement responsive design with Tailwind CSS
- Keep UI components in `src/components/ui` (excluded from formatting)
- create modular reusable components rather than big components.
- Follow accessibility best practices
