## Important Notes

### ES Modules
This project uses `"type": "module"` in package.json. Therefore:
- No need to create index.ts files for re-exports
- Import directly from source files
- Example: `import { ContactUs } from "./src/collections/Forms/config"` instead of `import { ContactUs } from "./src/collections/Forms"`
